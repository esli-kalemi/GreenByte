# Green Byte 🌱

**Green Byte** is a responsive, eco-friendly business website designed to present sustainable digital solutions for businesses. The website combines modern web design with a sustainability-focused theme to communicate how technology can contribute to a greener future.

## 🌍 About the Project

Green Byte focuses on providing digital solutions that help businesses improve efficiency while reducing unnecessary resource consumption.

The website presents the company's services, values, advantages, and contact information through a clean and environmentally inspired interface.

## ✨ Features

* **Responsive navigation**

  * Navigation menu linking to the main sections of the website
  * Mobile-friendly menu toggle

* **Hero section**

  * Main introduction and sustainability-focused message
  * Background image/visual design with an overlay

* **Services section**

  * Sustainable Web Development
  * Green Cloud Solutions
  * Digital Optimization
  * Eco-Friendly Digital Consulting

* **About Us section**

  * Introduction to Green Byte
  * Explanation of the company's mission
  * Supporting image

* **Why Green Byte section**

  * Sustainable by Design
  * Innovation with Purpose
  * Efficient & High-Performance
  * Built Around You

* **Contact section**

  * Company contact information
  * Contact form with fields for:

    * Name
    * Email
    * Message
  * Validation and success/error messages handled with JavaScript

* **Responsive design**

  * Designed to work across desktop, tablet, and mobile screen sizes

## 🛠️ Technologies Used

* **HTML5** – Structure and semantic organization of the website
* **CSS3** – Styling, layout, animations, and responsive design
* **JavaScript** – Interactivity, navigation behavior, and contact form validation
* **Google/External Fonts or Icons** – If included in the CSS
* **Images** – Used to support the visual identity of the website

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Open the project

Navigate into the project directory:

```bash
cd GreenByte
```

### 3. Run the website

Open `index.html` directly in your browser, or use **VS Code Live Server** for a better development experience.

With Live Server:

1. Open the project in VS Code.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server**.

The website should then open in your default browser.
